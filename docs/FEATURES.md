# 功能详解

## 多个独立的文献库

启动后的首页是文献库列表。每个文献库有自己的名称、主题描述和标识色，是数据目录下的一个独立文件夹（数据库、PDF、自定义词条都在里面），可以单独备份或拷走。

## 收集

- 粘贴 DOI 或 PMID：从 Crossref 和 Europe PMC 查询题目、作者、期刊、年份、摘要。
- 拖入或选择 PDF：提取文字，在前两页找 DOI 并查询元数据；找不到 DOI 时以文件名建条目。
- 导入 BibTeX / RIS；手动录入。
- 按 DOI、PMID、题目去重，重复导入不会产生重复条目。

## 整理

- 搜索（题目、作者、DOI、标签、词条、摘要、笔记）、筛选、排序。
- 阅读状态、收录判断、收藏、标签、笔记。
- **自定义词条**：每个文献库自己定义字段（文本 / 多值 / 单选），可填写、筛选、作为表格列。
- 回收站：删除的文献可恢复，并继续阻止同一篇被重复导入。
- 导出 BibTeX、CSV（当前列表）。

## PDF 预览

在详情面板里直接看 PDF，可展开成阅读宽度。渲染用纯 Rust 的 [hayro](https://github.com/LaurenzV/hayro)，不依赖系统 PDF 库。

## 建库向导

- 新建文献库后先问从哪里开始：从检索文献开始、导入已有的文献，或者先空着。
- 从检索开始：写下主题或关键词，助手为所选的数据库各拟几条取向不同的检索式，并逐条试检索；你按命中的文献选出靠谱的，保存并导入。已有的文献库也可以从「检索与导入」页进入。

## 检索与导入

- 为 PubMed、Europe PMC、Crossref、arXiv 保存检索式；「试检索」显示数据库命中总数和最新的记录，并标出哪些已在库中。
- 「运行并导入」把新文献加入文献库（都是「待判断」），已有的跳过；每次导入可以整批撤销，处理过的文献会保留。
- 自动更新（默认关闭）：每 6 小时、每天或每周运行已启用的检索式。应用开着时每分钟检查一次；关着时错过的，下次打开时补上；失败的最多一小时后重试。不开窗口时可以让系统的计划任务定期执行 `wisp sync_searches`（见[命令行与 MCP](CLI.md)）。

## 筛选

- 「筛选」页列出待判断的文献。助手阅读每一篇（有全文读全文，否则读摘要），给出建议、理由、一句逐字引自原文的依据和把握；引文不在原文里的不会被当作依据。
- 批量进行：几篇同时读（1 到 8 篇，在「设置 › AI」里定），页面上有进度条和正在读的文献。个别文献没判断成不会打断这一轮，连续三篇失败才停下；没判断成的留到下一轮。
- 判断完的队列按助手的建议分组（已纳入、相关、证据不足、不相关、还没有建议），可以只看其中一组。
- 建议只是建议：每一篇的收录判断由你确认，可以采纳，也可以另选；看过一组之后，也可以把整组按建议一次采纳（会先问一遍）。外部 agent 通过 MCP 或命令行只能提建议。

## 翻译

- 文献详情的「摘要」旁有「翻译」：题目和摘要译成中文，显示在原文上方。打开以后，之后点开的每一篇都会翻译，直到点「隐藏译文」。
- 译过的文字保存在文献库里，同一段文字不会请求第二次。翻译的要求（目标语言、术语、格式）可以在「设置 › AI」里改；改了以后按新的要求重新翻译。

## 提问

- 向文献库提问：范围是当前列表（受视图、搜索、筛选影响），模型读到每篇的记录、笔记，以及已存 PDF 中与问题相关的页面。
- 就单篇文献提问：模型读到该文献的记录和全文。
- 材料不够时，助手会自己调用工具在整个文献库里检索全文、按页翻阅、查询记录。一轮调用收成一行（「检索全文 ×2 · 读取全文」），点开看每次调用和结果；只读的调用并行执行。
- 助手要运行检索式导入文献、撤销导入或删除检索式时，会先停下来等你同意：允许这一次、这次对话里都允许，或者不允许。
- 回答过程中可以随时停止；已经写出的部分留在对话里，可以接着问。模型服务繁忙或连接失败时自动重试两次。
- 提问可以带图片（最多 8 张）：直接粘贴截图，或点输入框左边的「+」选择文件。过大的图片会先缩小，TIFF、BMP 会转成 PNG。所选的模型需要支持图片输入。
- 回答按 Markdown 排版：标题、加粗和斜体、列表、表格、引用、代码块，链接可以点开。
- 回答里的 `[P3 p.5]` 出处可以点击：打开这篇文献的 PDF 并跳到所引的页；助手引了原句时，这句话会在页面上高亮（那一页没有就在全文里找，找不到会明说）。筛选建议里的原文依据同样可以点击。
- 一个回答引了很多文献时，下面先列出前 8 个出处，其余的点「另外 N 个出处」展开。
- 输入 `/` 弹出命令列表，继续输入（英文名或中文说明里的字）筛选，↑↓ 选择，Enter 或 Tab 确认：`/search 词语` 在全文和记录里检索；`/cite 一段文字` 为这段文字逐句从库里找可以引用的文献；`/review 主题` 写一段带引用的小综述；`/compare P1 P3` 比较几篇文献的方法和结论；`/new` 开始新对话。
- 支持 Claude API、OpenAI 兼容的 chat/completions 和 OpenAI 的 Responses 接口。
- 对话保存在文献库里。点「历史」列出向文献库（或向这篇文献）提过的问题，点开一次对话可以接着问：模型会按文献库现在的内容重新读材料，以前回答里的 `[P3]` 仍然指向原来那篇文献。历史对话可以逐条删除。

## 设置

单独的设置页（首页或文献库侧栏的「设置」，默认 `Ctrl` / `⌘` + `,`），改动即时保存。

- **通用**：数据目录、自动检查更新。
- **外观**：跟随系统 / 浅色 / 深色，文献列表的行高。
- **快捷键**：搜索、添加文献、导入 PDF、提问等都可以改键、移除或恢复默认。
- **AI**：可以放进多个模型服务，提问、批量筛选、翻译各用哪一个分别指定（没指定的跟随提问的模型）。三种接口：Claude API、OpenAI 兼容的 chat/completions、OpenAI 的 Responses（/responses）。每个模型有自己的思考设置：默认（不发送参数）、关闭，或低到最高五档；翻译这样的任务可以用一个关闭思考的小模型。模型服务可以单独指定代理，或者填 direct 不走代理。
- **网络**：全局代理（http、https、socks4、socks5 等），文献检索、元数据查询、检查更新和模型请求都经过它；留空时跟随环境变量 ALL_PROXY / HTTPS_PROXY / HTTP_PROXY。命令行 `wisp` 用同一个设置。
- **关于**：版本、检查更新、项目主页。
