# 数据与隐私

## 本 fork 的写作请求

输入中文本身不自动调用模型。点击「寻找语料」会把当前查找文本（右侧指定内容，或中间当前段落）提交给已配置的翻译模型，得到英文表达与关键词，再检索本地已保存原句。英文查找不需要这一意图请求。

点击候选句会把该句和标题提交给翻译模型生成中文译文，按标题、原句和翻译规则缓存到当前库；不为单句翻译上传整篇 PDF。点击「AI 帮我写」会发送当前章节草稿、写作要求及至多 12 条有效候选原句给已配置的提问模型，建议经用户采用后才写回草稿。用户应根据所配置服务决定是否提交这些材料；停止等待不保证终止远端处理。

草稿、写作要求、最近建议及保留原稿存于本地文献库。此 fork 的更新检查只访问 Yu-Qiao-sjtu/WispPaper 的发布地址。其余功能沿用下述上游数据行为。

## 数据在哪里

| 内容 | 位置 |
|---|---|
| 文献库 | `文档/WispPaper/<文献库 ID>/`，内含 `library.json`、`wisp-paper.sqlite`、`papers/` |
| 历史对话（问题、回答、随问题发出的图片） | 各文献库的 `wisp-paper.sqlite` 里，随文献库文件夹一起走；在「历史」里删除一条对话是真的删除 |
| 被移除的文献库、附件 | 同目录下的 `removed/`（只移动，不删除） |
| 设置 | 系统配置目录下的 `WispPaper/settings.json` |

数据目录可以在「设置 › 通用」里更改。环境变量 `WISP_PAPER_HOME` 可把数据和设置一起指到别处（测试用）。

附件在数据库里记的是相对于文献库文件夹的路径，所以整个文件夹可以拷到别处继续用。

从 Zotero 导入时，只读打开用户选择的本地 `zotero.sqlite`，把文献信息和本地 PDF 复制到当前 Wisp Paper 文献库；不会改动 Zotero 记录或移动原附件。这一步不访问网络，也不调用 AI。导入范围和附件限制见 [Zotero 导入教程](ZOTERO.md)。

## 会离开本机的数据

| 操作 | 发出的内容 | 发给谁 |
|---|---|---|
| DOI / PMID 查询 | 编号 | Crossref 和 Europe PMC |
| 试检索、运行检索式（包括自动更新） | 检索式 | 所选的数据库：PubMed、Europe PMC、Crossref 或 arXiv |
| 向导拟检索式 | 文献库的名称、主题和你写的关键词 | 你为提问指定的模型服务 |
| 助手筛选 | 筛选标准和每篇文献的记录、摘要、全文 | 你为批量筛选指定的模型服务 |
| 翻译 | 文献的题目和摘要，以及翻译的要求 | 你为翻译指定的模型服务 |
| 提问 | 问题和随它粘贴的图片、相关文献的记录、笔记、全文页面 | 你为提问指定的模型服务 |
| 检查更新 | 对本项目 `releases/latest` 的一次请求 | GitHub |

检查更新只读取 `releases/latest` 跳转到的版本号，不下载、不上传任何内容；可在「设置 › 通用」关闭，新版本需要自己到发布页下载安装。

## API Key

API Key 以明文保存在 `settings.json`。留空则读取环境变量 `ANTHROPIC_API_KEY` / `OPENAI_API_KEY`。
